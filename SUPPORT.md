# Getting support

Thanks for using LombokCSS! Here is where to go for help.

## Questions & usage help

- **GitHub Discussions:** <https://github.com/codinglombok/LombokCSS/discussions>
  — best for "how do I…", theming questions, and sharing what you built.
- **Documentation:** <https://codinglombok.github.io/LombokCSS/> — Overview,
  Getting started, Migration from Bootstrap, Theming, Components, Forms, Utilities.

## Bugs & feature requests

- **Issues:** <https://github.com/codinglombok/LombokCSS/issues> — use the Bug
  report or Feature request template. Please include a minimal reproduction,
  the `data-style`/`data-theme`/`dir` in use, browser/OS, and version.

## Security

- **Do not** open a public issue. See [SECURITY.md](SECURITY.md) for private
  reporting via GitHub Security Advisories.

## What's supported

- Latest released `0.1.x`. Older versions are not maintained.
- Install via npm, CDN (jsDelivr/unpkg), GitHub Packages (Container, NuGet,
  RubyGems, Maven, npm), or a direct download — see the **Getting started**
  docs for each method.

## Response expectations

This is a community open-source project; responses are best-effort. Clear,
reproducible reports get answered fastest. PRs are welcome — see
[CONTRIBUTING.md](CONTRIBUTING.md).
